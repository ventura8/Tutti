# Tutti

Tutti is a free, open-source tool that runs on your own computers. It shares AI coding agents, local models and machines
across a household or a small team: one orchestrator, many workers, with queues, fall-over routing and usage pacing.

- **Source code and install:** <https://github.com/ventura8/Tutti> ([how to install](INSTALL.md))
- **Sign-in with Google:** the dashboard uses it to know who is the administrator. See [AUTH.md](AUTH.md).
- **Architecture:** [ARCHITECTURE.md](ARCHITECTURE.md)
- **API reference:** [API.md](API.md): the CLI, the dashboard's HTTP API, the MCP tools and the config file
- **Privacy policy:** [PRIVACY.md](PRIVACY.md)
- **Terms of use:** [TERMS.md](TERMS.md)
- **Report a problem:** the dashboard's **Report a problem** button, `tutti report`, or
  [a GitHub issue](https://github.com/ventura8/Tutti/issues/new/choose).
